# Backlog

Freeform article ideas and outlines that aren't tied to a single episode. This folder is **not** loaded by Astro — nothing here can appear on the site.

Per-episode ore files (`ep-{N}-angles.md`) live in `angles/`, not here.

When you start writing a real post, move it to `drafts/` with full front matter (`npm run new-post` scaffolds there).
When ready to ship, move to `published/YYYY-MM/` (from the post date) and set `draft: false`.
